## 1. Git仓库使用步骤

- 本地使用 VS Stdio 打开仓库文件夹
  - ![image-20250112201320898](images/git%E4%BB%93%E5%BA%93%E4%BD%BF%E7%94%A8%E6%AD%A5%E9%AA%A4/image-20250112201320898.png)
- 打开文件夹后，进入git更改栏
  - ![image-20250112201512706](images/git%E4%BB%93%E5%BA%93%E4%BD%BF%E7%94%A8%E6%AD%A5%E9%AA%A4/image-20250112201512706.png)
  - 输入提交项目注释
  - 然后点击全部提交下拉栏中的【全部提交并公布】，之后等待本地仓库同步到服务器端

## 2. Gitee

	- ![image-20250112201834067](images/git%E4%BB%93%E5%BA%93%E4%BD%BF%E7%94%A8%E6%AD%A5%E9%AA%A4/image-20250112201834067.png)
	- 登录我的gitee账号，就会进入，在<代码>栏可以追溯提交历史记录
	- 点击<克隆/下载>会将服务器仓库端的代码下载到本地文件
